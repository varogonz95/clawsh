Every session, one tab.

clawsh web puts every machine and every Claude session in a browser tab. Start one, watch it work, step in, close the tab. Claude keeps going.

Open it with clawsh web Prefer the terminal?

One command, no install

It's part of the same binary and reads the same hosts.toml as clawsh ls.

$ clawsh web
clawsh web: open http://127.0.0.1:7421/?k=…
(Ctrl-C to stop)
  • It opens your browser for you. Ctrl-C stops the page, never the sessions.
  • Loopback only, with a fresh access key on every launch. The browser talks to clawsh web, never to the agents.
  • Phones and other devices are next (#6), then editing machines from the page (#8).

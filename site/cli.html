All your Claudes, one shell.

Everything the web UI does, from any terminal. Start Claude Code on any machine in your network, leave it working, and scuttle back in from whichever terminal you're at.

A crab on every machine, a shell wherever you are.

It's the same binary in both places.

clawsh agent

Runs on each machine that hosts sessions. It keeps claude running in a terminal of its own, so the work carries on after you leave, and it remembers recent output for when you come back.

clawsh ls, new, attach, kill

Run them from any terminal. They read your list of machines and talk to each agent over your LAN. Attaching takes over your terminal; Ctrl+] hands it back and leaves claude working.

Up and scuttling

Install clawsh, start an agent on each machine and list them in hosts.toml: the install steps cover it. Then:

  1. Check every machine answers

    Each agent reports its name, OS and version.

    clawsh hosts

  2. Start a session and attach

    Anything after -- goes straight to claude. --detached starts it without attaching.

    clawsh new desk --dir ~/src/api -- --resume
clawsh attach desk/8158   # an ID prefix is enough

Before relying on it, read what doesn't work yet and the security notes.
